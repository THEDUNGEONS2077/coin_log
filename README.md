# coin_log

A lightweight, offline budgeting app for Android, in a yellow terminal style. It's built from [quest_log](https://github.com/THEDUNGEONS2077/quest_log).

- **Salary in:** what goes to savings comes off the top, you choose what goes to credit, and debit gets the rest.
- **Budget lines and bills:** set money aside for what's coming. Spare is what nothing is set aside for.
- **Log after you tap:** split one card tap over several budget lines and spare.
- **Never below zero:** coin_log refuses anything that would leave spare, a line or savings short.
- **Savings:** a running total, with moves to and from debit and credit.
- **No account, no internet:** everything stays on the phone. Backups are files you keep.
